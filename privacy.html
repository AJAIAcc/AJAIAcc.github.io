Privacy policy

Last updated 18 October 2026

Minerva is a personal assistant operated by Ajaydas Devadas (“the owner”) for his own use only. This policy explains what data Minerva accesses, how it is used and stored, and who it is shared with. Because Minerva has a single user, “you” and “the owner” are the same person.

Data Minerva accesses

  • Google user data, only after the owner grants access through Google's sign-in:
    • Gmail: message content, headers and attachments; labels and read/starred state; sending email the owner has approved.
    • Google Docs: the content of documents, to read them, create new ones and apply edits the owner has approved.
    • Google Drive: file names and contents (read-only), to find documents.
  • Other data the owner provides: messages and files sent to Minerva, his calendar (through a private calendar link), his location when he shares it, and, during sessions he approves on his phone, what is on his phone's screen.

How it is used

All of this data is used only to provide Minerva's features to the owner: answering his questions, summarising and organising his email and documents, reminders, alerts and briefings. It is not used for advertising, not sold, and not used to build profiles for anyone else.

To generate responses, relevant content is sent to Anthropic's Claude API. Under Anthropic's commercial terms, data sent through the API is not used to train their models by default. Minerva does not use Google user data to develop, improve or train AI models.

Google API Services: Limited Use

Minerva's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. In particular, Google user data is used only to provide or improve user-facing features the owner uses; it is not transferred to others except as needed to provide those features (the AI processing described above), to comply with law, or as part of a security review; it is not used for advertising; and no person reads it except the owner, or with his explicit agreement.

Storage and security

  • Minerva runs on a private server (DigitalOcean, Singapore region) that only the owner can access, using key-based login and a firewall.
  • Google sign-in credentials are stored on that server with restricted file permissions and are never shown in messages.
  • Email and document content is fetched when needed and not kept in bulk. Minerva keeps its conversation history with the owner, short notes and summaries he has asked it to remember, and logs of actions it has taken, so that it can be useful over time.
  • Database backups are kept on the same server for seven days.

Sharing

Data is not shared with anyone except the service providers Minerva needs in order to work: Anthropic (AI processing), Telegram (message delivery to the owner), DigitalOcean (hosting) and Google (the owner's own Google services).

Your control

  • Google access can be removed at any time at myaccount.google.com/permissions.
  • The owner can ask Minerva to forget anything it has stored, clear its conversation history, or delete all of its data from the server.
